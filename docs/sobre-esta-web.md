# Sobre esta web

## Qué es esta página

Esta web es la **presentación del proyecto** Partida Guardada, el primer ejercicio del Proyecto Intermodular de 2º de Desarrollo de Aplicaciones Multiplataforma.


## Cómo está hecha

El contenido está escrito en *Markdown* y la web se genera con [MkDocs](https://www.mkdocs.org) y el tema [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/).

Para verla en tu equipo, desde la carpeta del repositorio:

```bash
pip install -r requirements.txt
mkdocs serve
```

Y para comprobar que no tiene enlaces rotos:

```bash
mkdocs build --strict
```
